# Vườn ươm Công nghệ 4 — mô hình 3D tương tác

Mô hình 3D chạy trên trình duyệt giúp học sinh lớp 4 thực hành trồng và chăm sóc hoa, cây cảnh trong chậu
(Công nghệ 4, bộ Chân trời sáng tạo, Bài 2 → Bài 5 và Dự án 1). Ảnh và mô hình do tác giả tự dựng; nội dung chỉ tóm tắt các bước thực hành.

- Bài 2: chậu, giá thể, dụng cụ · Bài 3: gieo hạt hướng dương, trồng hoa mười giờ · Bài 4: trồng cây lưỡi hổ
- Bài 5: chăm sóc dừa cạn, lưỡi hổ + luyện tập · Dự án 1: trồng hoa trang trí lớp học

Mở `index.html` bằng Chrome/Edge (cần mạng để tải thư viện three.js). Thầy Phong — TH Gò Công Tây.
